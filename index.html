    Layer & filter

    Centang untuk menampilkan. Layer yang terakhir dicentang tampil paling atas. Periode titik api diatur di panel atas peta.

    Pemodelan bahaya

    Metode: weighted overlay dua tingkat dengan bobot kelompok dari AHP. Dipilih karena data parameter tersedia lengkap secara spasial sedangkan data kejadian dipisahkan untuk pengujian; metode berbasis data (FR/ML) membutuhkan titik api sebagai data latih sehingga bersaing dengan kebutuhan validasi independen. Setiap perubahan di bawah langsung menghitung ulang peta.
